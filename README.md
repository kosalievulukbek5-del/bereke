# Береке — продуктовый магазин

## О проекте

Береке — одностраничный сайт-каталог продуктового магазина,
созданный в рамках практического экзамена по Frontend.

## Использованные технологии

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Flexbox
- CSS Grid
- Git и GitHub

## Основные функции

- Адаптивное меню
- Главный экран
- Информация о магазине
- Карточки продуктов
- Динамический каталог товаров через JavaScript
- Массив объектов с тестовыми данными
- Метод forEach
- Изменение DOM
- Обработка нажатий кнопок
- Форма обратной связи с валидацией
- Сообщения об ошибке и успехе
- Таймер setTimeout
- Сохранение избранного в localStorage
- Восстановление избранного после перезагрузки

## Особенности

Сайт использует готовый массив товаров вместо API.
База данных и сервер не используются.

Форма демонстрирует проверку данных и не отправляет
сообщения на сервер.

## Адаптивность

Сайт рассчитан на компьютер, планшет и телефон.
Используются CSS Grid, Flexbox и media queries.

## Запуск

Откройте index.html в браузере или запустите сайт
через Live Server в VS Code.

Для Bootstrap CDN требуется подключение к интернету.
